# Clash Mate 二次开发

基于 [ClashMetaForAndroid](https://github.com/MetaCubeX/ClashMetaForAndroid)，拼夕夕订阅自动同步，与正版完全隔离。

| 项目 | 正版 CMFA | 二次开发版 |
|------|-----------|-----------|
| 应用名 | Clash Meta | Clash Mate 二次开发 |
| 包名 | com.github.metacubex.clash.meta | com.wzpxx.clashmate.dev |
| 拼夕夕订阅更新 | 手动/15分钟起 | 默认 5 分钟 |

## GitHub Actions 构建

1. 推送到 GitHub
2. Actions → Build Clash Mate 二次开发 → Run workflow
3. 从 Artifacts 下载 APK
